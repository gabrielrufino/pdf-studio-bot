# PDF Studio Bot Documentation

This folder contains living documentation for every bot feature, as well as business and technical overviews.

## Structure

- [business.md](./business.md) — Business model, value proposition, personas, and monetization.
- [technical.md](./technical.md) — Architecture, request lifecycle, middleware stack, and infrastructure.
- [error-handling.md](./error-handling.md) — Global error classification and user-facing behavior.
- [usage-limits.md](./usage-limits.md) — Free and PRO daily usage enforcement.
- [reengagement.md](./reengagement.md) — Weekly re-engagement cron job.

## Feature Docs

Each feature has its own file at the root of this folder:

- [Start](./start.md) — Onboarding and user registration.
- [Help](./help.md) — Interactive command menu.
- [Language](./language.md) — Language switching.
- [Download](./download.md) — Download a PDF from a URL.
- [Compress](./compress.md) — Compress a PDF file.
- [Join](./join.md) — Join multiple PDFs into one.
- [Split](./split.md) — Split a PDF into individual pages.
- [Extract](./extract.md) — Extract a page range from a PDF.
- [Rotate](./rotate.md) — Rotate a PDF.
- [PdfToImages](./pdftoimages.md) — Convert PDF pages to images.
- [ExtractText](./extracttext.md) — Extract text from a PDF.
- [PutPassword](./putpassword.md) — Protect a PDF with a password.
- [RemovePassword](./removepassword.md) — Remove password protection.
- [Pro](./pro.md) — PRO subscription via Telegram Stars.
- [Feedback](./feedback.md) — Send feedback.
- [Version](./version.md) — Show bot version.
